# Resta - الإعدادات المبسطة (`resta_settings`)

## مركز الإعدادات
الإعدادات ← مركز الإعدادات (`/odoo/settings-center`) بنفس شكل الثيم الجانبي ورحلة النمو:
- **تجهيز المطعم**: قائمة خطوات بنسبة إنجاز (بيانات المنشأة، الربط مع هيئة الزكاة، الفروع، نقاط البيع، طرق الدفع، المنيو، شاشة المطبخ، المستخدمون، الحساب البنكي، الموظفون). كل خطوة تفتح مكانها.
- **بطاقة لكل قسم** مرتبة مثل القائمة الجانبية (التشغيل، المبيعات، المالية، الأشخاص، المنشأة) مع روابط سريعة.
- مع رحلة النمو: شريط المستوى الحالي، والأقسام المقفلة تظهر «تُفتح بإكمال مستوى ...».
- بحث واحد في كل الإعدادات.

## صفحة الإعدادات
- ترتيب الأقسام مثل القائمة الجانبية، وقسم «الفوترة» اسمه «المحاسبة».
- إخفاء ميزات إنتربرايز غير الموجودة على السيرفر (كانت تفتح نافذة بيع).
- نقل ما لا يخص المطاعم (شركات الشحن، أجهزة دفع أجنبية، LDAP، الأداء...) إلى «الإعدادات المتقدمة» (وضع المطور، للمسؤولين فقط).
- كل قسم بطاقة، وترجمة عربية لإعدادات موديولاتنا التي لم تُترجم بعد.

الاختبارات: `--test-tags /resta_settings`.
