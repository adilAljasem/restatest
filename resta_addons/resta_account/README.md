# Resta – المحاسبة والتقارير المالية (`resta_account`)

مبنية من الصفر على **Odoo 19 Community**. لا تحتاج `account_accountant` ولا `account_reports` ولا اشتراك Odoo.

## ما تضيفه

| الميزة | التفاصيل |
|---|---|
| قوائم المحاسبة الكاملة | القيود، دفتر اليومية، الإقفال. مستويات صلاحية: محاسب (للقراءة)، محاسب، مدير محاسبة |
| قائمة الدخل | الإيرادات، تكلفة الإيرادات، مجمل الربح، المصروفات، الإهلاك، الربح التشغيلي، صافي الربح. مقارنة بالفترة السابقة أو السنة الماضية |
| قائمة الدخل حسب الفرع | عمود لكل فرع (الحساب التحليلي) + الإجمالي |
| الميزانية العمومية | الأصول والالتزامات وحقوق الملكية مع أرباح السنة والأرباح المبقاة، وعلامة «متوازنة» |
| ميزان المراجعة ودفتر الأستاذ | رصيد افتتاحي، مدين، دائن، رصيد ختامي، والحركات تحت كل حساب |
| كشف حساب العملاء والموردين | لكل شريك مع الحركات |
| أعمار الذمم | غير مستحق، 1-30، 31-60، 61-90، 91-120، أكثر من 120، وكما في أي تاريخ سابق |
| إقرار ضريبة القيمة المضافة | يقرأ نموذج الإقرار السعودي الموجود في `l10n_sa` (المبيعات والمشتريات حسب البند) |
| فلتر الفروع | كل التقارير تُفلتر بالفرع (التوزيع التحليلي، مع النسب) |
| التصدير | Excel، وطباعة / PDF من المتصفح. الضغط على أي مبلغ يفتح القيود خلفه |
| التسوية البنكية | حركة البنك ← الفواتير المقترحة (نفس المبلغ أو رقم الفاتورة في البيان) ← تسوية. جزئية، أو الباقي على حساب (رسوم بنكية) |
| الأصول الثابتة | قسط ثابت شهري، ترحيل تلقائي، أصل تلقائي من فاتورة المورد، بيع أو استبعاد بقيد |
| إقفال الفترات | تواريخ إقفال المبيعات والمشتريات والضريبة وكل القيود |
| قائمة التدفقات النقدية | الطريقة المباشرة: كل قيد حرّك النقد يُصنَّف حسب طرفه الآخر (عملاء، موردون، مصروفات، أصول، تمويل). تشمل المبالغ تحت التحصيل، والتحويل بين البنوك لا يُحتسب |
| استيراد كشف البنك | Excel و CSV من بوابة البنك (تتعرّف على الأعمدة بالعربي أو الإنجليزي، مدين/دائن أو مبلغ، الأرقام العربية)، و CAMT.053 و OFX و MT940. معاينة قبل الاستيراد وتجاهل الحركات المستوردة سابقاً |
| الموازنات | موازنة لكل فرع شهراً بشهر، تعبئة تلقائية من فعلي السنة الماضية مع نسبة نمو أو مبلغ سنوي، وتقرير «الموازنة مقابل الفعلي» مع نسبة التحقق |
| المؤجلات | تاريخ بداية ونهاية على سطر الفاتورة (إيجار سنة مقدماً، عقد صيانة...) فيُنقل المبلغ لحساب المدفوع مقدماً / الإيرادات المؤجلة ويُثبت شهرياً حسب الأيام. الأشهر القادمة تُرحَّل تلقائياً في تاريخها |
| متابعة التحصيل | شاشة واحدة: المستحق والمتأخر لكل عميل، الإجراء التالي، إرسال تذكير بالبريد مع كشف الحساب، رابط واتساب، مهمة اتصال، تأجيل أو إيقاف. ثلاثة مستويات جاهزة (7 و30 و60 يوماً) تعمل يومياً |

## المسار
المحاسبة ← التقارير ← (القوائم المالية / تقارير الشركاء / الضرائب / الإدارة: الموازنة مقابل الفعلي)، والمحاسبة ← المحاسبة ← التسوية البنكية، استيراد كشف بنكي، الأصول الثابتة، الموازنات، والعملاء ← متابعة التحصيل.

الاختبارات: `--test-tags /resta_account` (25 اختباراً).
