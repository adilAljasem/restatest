# Resta – الباركود والمخزون (`resta_barcode`)

تطبيق مسح للمخزون مبني من الصفر على **Odoo 19 Community** بدون `stock_barcode`. يعمل على الجوال والتابلت والكمبيوتر.

- **طرق المسح**: قارئ الباركود (USB / بلوتوث)، أو كاميرا الجوال (Chrome على أندرويد)، أو الكتابة.
- **استلام بضاعة**: كل مسحة +1، وباركود الكرتون يضيف كمية الكرتون. الصنف غير المطلوب يُضاف للاستلام. زر «الكل كما هو متوقع».
- **التحويل والصرف**: مسح الأصناف المطلوبة فقط، مع تنبيه للصنف غير الموجود في الحركة.
- **الاعتماد**: عند وجود نقص يسأل: إنشاء حركة بالمتبقي أو الإغلاق بدون المتبقي.
- **رقم التشغيلة / الصلاحية**: يطلبه للأصناف المتتبعة.
- **الجرد**: اختر المخزن أو امسح باركود الموقع، ثم امسح الأصناف أو اكتب العدد، وتظهر الفروقات قبل الاعتماد.
- **فتح مباشر**: مسح رقم الحركة (مثل WH/IN/00012) يفتحها.

القائمة: تطبيق «الباركود»، أو المخزون ← العمليات ← الباركود. الاختبارات: `--test-tags /resta_barcode` (8 اختبارات).
