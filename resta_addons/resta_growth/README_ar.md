# رحلة النمو (`resta_growth`) — المرحلة 1

موديول يُثبَّت في قاعدة كل مطعم على منصة ريستا. يحوّل النظام من «كاشير» إلى رحلة نمو من خمسة مستويات: يقيس انضباط المطعم من بياناته الفعلية، ويفتح له ميزات مع كل مستوى، ويرافقه بدروس وجولات إرشادية داخل المتصفح.

## ماذا يفعل
| الجزء | الوصف |
|---|---|
| ملف المطعم | نوع المطعم، المدينة، أيام العطلة والإجازات، الخطة، الموافقات (كل موافقة مستقلة وقابلة للسحب) |
| المستويات الخمسة | التأسيس ← الانضباط ← الربحية ← النمو ← التوسع. شروط المستويين 1 و2 كاملة في هذه المرحلة |
| محرك الشروط | كل شرط سجل قابل للتعديل، ويقابله دالة بايثون مسجّلة (بلا `safe_eval`) |
| مؤشر الانضباط | 0–1000 على نافذة 90 يوماً، أربعة مكوّنات، لقطة يومية غير قابلة للتعديل، «قيد التكوين» قبل 14 يوماً، سبب ونصيحة لكل مكوّن |
| مؤشر جودة الإدخالات | 0–100، يقرر الشهر المجاني في الأشهر 4–6 (الحد 85) |
| قفل الميزات | المخزون يُفتح بإكمال المستوى 1، والمحاسبة بإكمال المستوى 2. القفل على القوائم والروابط فقط، وصلاحيات النماذج لا تُمس، فنقاط البيع تعمل كما هي |
| الواجهة | شارة المستوى أعلى الشاشة، صفحة «رحلتي»، معالج الترحيب، احتفال الترقية، صفحة ودية للميزة المقفلة |
| الجولات | جولة الترحيب + 4 جولات للمستوى 1 (إضافة صنف، فتح وإغلاق الجلسة، الفاتورة الإلكترونية، إعلان إجازة) |
| المحاكي | لفريق الدعم فقط وبعلَم صريح: 120 يوماً من البيانات التجريبية، نقل لأي مستوى، معاينة الاحتفال، إعادة الضبط |

## كيف يُحسب كل شيء
1. **كل ليلة 3:00 فجراً (الرياض)** يجمع الـ Cron بيانات اليوم في جدول «الحقائق اليومية» (`resta.growth.daily`): الطلبات، الجلسات، فروقات الصندوق، الفواتير الإلكترونية، الاستهلاك، الهدر، الجرد.
2. من هذه الحقائق تُحسب الشروط ثم المؤشر، وتُحفظ لقطة اليوم.
3. الواجهة تقرأ النتائج المخزنة فقط، ولا يُحسب شيء عند فتح الصفحة.
4. أول تشغيل على مطعم قائم يعيد بناء آخر 120 يوماً من بياناته.
5. زر **«تحديث الآن»** (لفريق الدعم) يعيد الحساب فوراً.

## التثبيت
- **المطاعم الجديدة:** يُثبَّت تلقائياً، لأن `resta-init` يضيفه لقالبي النسختين.
  - عند إنشاء مطعم جديد يُنشأ لصاحبه **حساب مستقل** بصلاحيات العمل كاملة، بدون صلاحية مدير النظام التقني.
  - حساب `admin` يتحول إلى «دعم ريستا» (`resta-support`) لفريق بيسك سلوشن.
- **قوالب ومطاعم قائمة على السيرفر:**
  ```bash
  docker exec resta_odoo resta-upgrade --install resta_growth
  ```
  - يثبّته على القوالب وقواعد المطاعم فقط، ويتخطى قاعدة المنصة.
  - في هذه القواعد يبقى `admin` هو المالك (وضع قديم) إلى أن يفصل الدعم الحسابين.
- **بعد أي تعديل على الموديول:** `docker exec resta_odoo resta-upgrade resta_growth`

## أين تُعدّل الأرقام والنصوص (بدون كود)
| ماذا | أين |
|---|---|
| أهداف الشروط ونوافذ الأيام والحدود (15 صنفاً، 30 يوماً، 95%، 99%، 6 أسابيع، 80%، 10 ريال، 0.5%، 90%) | رحلة النمو ← الإعدادات ← الشروط |
| حد الهدر والهامش لكل نوع مطعم | رحلة النمو ← الإعدادات ← أنواع المطاعم |
| أوزان المؤشر، الشرائح، حد الشهر المجاني، أيام التكوين، تفعيل المحاكي | الإعدادات ← رحلة النمو |
| أسماء المستويات، الجوائز، رسائل الاحتفال، الألوان | رحلة النمو ← الإعدادات ← المستويات |
| الميزات والقوائم المقفلة | رحلة النمو ← الإعدادات ← الميزات |
| نصوص الدروس وروابط الفيديو | رحلة النمو ← الإعدادات ← الدروس والجولات |
| الترجمة | `i18n/ar.po` و`i18n/resta_growth.pot` |

> كل هذه القوائم تظهر لمجموعة «فريق بيسك سلوشن (الدعم)» فقط.

## الصلاحيات
| المجموعة | ترى |
|---|---|
| صاحب الحساب | الشارة، صفحة الرحلة، المؤشر، الاشتراك، الدروس، استلام الجائزة، ملف المطعم والإجازات، صفحات الإعدادات التجارية |
| مدير الفرع | الشارة والمؤشر والدروس، بدون الاشتراك والفوترة، ولا يستلم الجوائز |
| الكاشير والموظفون | لا شيء من الرحلة |
| فريق بيسك سلوشن | كل شيء، يتجاوز القفل، أدوات «تحديث الآن» والمحاكي |

## الاختبارات
```bash
odoo-bin -d <قاعدة تجريبية> -i resta_growth --test-enable --test-tags /resta_growth --stop-after-init
```
- **اختبارات `TransactionCase`: 34 اختباراً.** تغطي:
  - كل دوال الشروط والتجميع اليومي.
  - المؤشر واللقطات غير القابلة للتعديل.
  - القفل وعدم إعادة القفل، وخطة `paid_full`.
  - استلام الجائزة، والصلاحيات، والمحاكي.
  - فصل حساب المالك، وحفظ المالك للإعدادات.
  - نجحت كلها على قاعدة نظيفة من قالب الداين إن.
- **اختبارات `HttpCase`: 3 اختبارات** (الشارة للمالك فقط، عدم ظهورها للكاشير، تشغيل جولة الترحيب). تحتاج ملفات الاختبار الأصلية لموديولات أودو، ونسخة أودو المخففة حذفتها، فلا تعمل عليها.
  - شغّلها على نسخة أودو كاملة.
  - نفس السيناريوهات جُرّبت في متصفح حقيقي ونجحت.
