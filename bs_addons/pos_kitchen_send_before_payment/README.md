# POS Send to Kitchen Before Payment (Odoo 19)

يضيف زر **إرسال (Send)** بجانب زر **الدفع** في نقطة البيع **بدون تفعيل وضع المطعم**،
لإرسال الطلب لطابعات المطبخ أو شاشة التحضير قبل الدفع (مناسب للدرايف ثرو والخدمة على الكاونتر).

## التفعيل
1. نقطة البيع ← التهيئة ← الإعدادات ← اختر نقطة البيع.
2. قسم **Preparation**: فعّل **Preparation Printers** وأضف طابعة المطبخ مع فئات المنتجات
   (أو اربط شاشة التحضير في نسخة Enterprise).
3. فعّل **الإرسال للمطبخ قبل الدفع** (Send to Kitchen Before Payment).
4. احفظ، ثم أغلق الجلسة وافتحها من جديد.

## السلوك
- يظهر الزر فقط عند وجود أصناف جديدة أو معدّلة تابعة لفئات المطبخ، ويعرض عددها لكل فئة.
- يُرسل فقط ما أُضيف أو تغيّر منذ آخر إرسال.
- عند الدفع لاحقاً لا تُطبع الأصناف المرسلة مرة ثانية؛ يُرسل فقط ما أُضيف بعد آخر إرسال.
- بعد الإرسال يبقى نفس الطلب مفتوحاً على الشاشة (لا يُفتح طلب جديد تلقائياً) حتى تكمل الدفع.
- لا يظهر الإعداد ولا الزر إذا كان وضع المطعم مفعّلاً (لأن المطعم يوفّر زره الخاص).
