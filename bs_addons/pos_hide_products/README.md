# Hide Products from POS and Self Order

Odoo 19 add-on that adds **Hide From POS & Self Order** to the product's
Point of Sale tab.

When selected, the product is removed from the direct product catalog and
search results in both the cashier POS and Self Order. The product remains
loaded where needed, so it can still be selected as a combo item or modifier,
sent to the kitchen display, and included on kitchen printer tickets.

## Installation

1. Add this repository to the Odoo addons path.
2. Update the Apps list.
3. Install **Hide Products from POS and Self Order**.

## Configuration

Open a product, enable **Point of Sale**, then open the **Point of Sale** tab
and select **Hide From POS & Self Order**.
