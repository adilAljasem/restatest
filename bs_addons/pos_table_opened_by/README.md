# POS Table Opened By (Odoo 19)

يظهر اسم الكاشير الذي فتح الطلب فوق رقم الطاولة في شاشة الصالة.

- الاسم يُحفظ مرة واحدة عند إنشاء الطلب، ولا يتغيّر إذا عدّله أو دفعه كاشير آخر.
- إذا كان "تسجيل الدخول بالموظفين" (pos_hr) مفعّلاً يظهر اسم الموظف، وإلا اسم المستخدم.
- يعمل مع موديول pos_shared_floor_sync، فيظهر الاسم في كل الصناديق.

## التثبيت
1. انسخ مجلد `pos_table_opened_by` إلى مسار الـ addons وأعد تشغيل Odoo.
2. التطبيقات ← تحديث قائمة التطبيقات ← ثبّت "POS Table Opened By".
3. أغلق الجلسات وافتحها من جديد (أو حدّث صفحة الـ POS).

ملاحظة: الطلبات المفتوحة قبل التثبيت ستُظهر اسم آخر كاشير عدّلها.
