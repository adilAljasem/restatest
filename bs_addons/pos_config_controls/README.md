# POS Configuration Controls

Odoo 19 addon providing four narrowly scoped POS controls:

- Force invoicing independently per POS.
- Disable only the automatic post-payment invoice PDF download per POS.
- Select a default customer on each new order per POS.
- Restrict members of **Restricted POS User** to the POS configurations listed in **Allowed POS** on their user form.

Install the addon, configure the first three options under **Point of Sale → Configuration → Settings**, and configure restricted users under **Settings → Users & Companies → Users → Access Rights**.
