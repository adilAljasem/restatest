# POS Shared Floor Sync (Odoo 19)

يجعل نقاط البيع (المطعم) المرتبطة بنفس الصالة ترى الطاولات المشغولة عند بعضها.

## التثبيت
1. انسخ مجلد `pos_shared_floor_sync` إلى مسار الـ addons وأعد تشغيل Odoo.
2. فعّل وضع المطوّر ← التطبيقات ← تحديث قائمة التطبيقات ← ثبّت "POS Shared Floor Sync".
3. نقطة البيع ← الإعدادات ← مخططات الصالات ← افتح الصالة ← أضف الصناديق الأربعة في حقل نقاط البيع.
4. أغلق الجلسات المفتوحة وافتحها من جديد على كل جهاز.

## كيف يعمل
- يربط الصناديق المشتركة في الصالة كـ "Trusted POS" لبعضها تلقائياً (Odoo يمنع ذلك لنقاط المطعم من الواجهة).
- عند فتح الجلسة يحمّل الطلبات المفتوحة للصناديق الأخرى على نفس الطاولات.
- بعدها يستخدم آلية المزامنة الأصلية في Odoo 19 لتحديث الطاولات فوراً عبر كل الصناديق.

## ملاحظات
- يجب أن تكون العملة والشركة نفسها لكل الصناديق.
- الطلب يُنسب للصندوق الذي عدّله/دفعه آخراً، فيدخل في تقفيل جلسته.
- جرّبه على نسخة تجريبية قبل الإنتاج.
