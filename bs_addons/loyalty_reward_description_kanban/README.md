# Loyalty Reward Description on Cards

This Odoo 19 add-on displays the **Description on order** value directly on
each reward card in a Discount & Loyalty program. Empty descriptions do not add
an extra row to the card.

## Installation

1. Add the repository to the Odoo add-ons path.
2. Update the Apps list.
3. Install **Loyalty Reward Description on Cards**.

The description then appears under the reward summary in **Point of Sale →
Products → Discount & Loyalty**.
