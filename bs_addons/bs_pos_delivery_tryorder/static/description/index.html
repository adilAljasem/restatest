BS POS Delivery TryOrder

Connect TryOrder to Odoo 19 Point of Sale through BS POS Delivery Core. Accepted orders appear in the shared POS board and restaurant preparation display.

Native products and options

Branch menus expose Odoo POS products, modifier option IDs, and combo choices. Product modifiers keep their parent link; instruction modifiers reach the kitchen without artificial products.

Core order and payment workflow

Core validates prices and taxes, maps cash, card, and wallet payments, manages order states, and dispatches status updates to TryOrder.

Configure a TryOrder connection, POS store binding, and payment methods in BS POS Delivery Core. See the module README for the HTTP contract and financial limits.
